## 🚀 Deploy to Vercel (Step by Step)

### Step 1 — Install dependencies locally
```bash
cd hanuman-construction
npm install
npm start   # Test locally at http://localhost:3000
```

### Step 2 — Push to GitHub
1. Go to https://github.com and create a new repository called `hanuman-construction`
2. Run these commands:
```bash
git init
git add .
git commit -m "Initial commit - Hanuman Construction website"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/hanuman-construction.git
git push -u origin main
```

### Step 3 — Deploy on Vercel
1. Go to https://vercel.com
2. Sign up / log in with your GitHub account
3. Click **"New Project"**
4. Import your `hanuman-construction` GitHub repo
5. Vercel auto-detects Create React App — click **"Deploy"**
6. Your site will be live at: `https://hanuman-construction.vercel.app`

### Step 4 — Custom Domain (Optional)
In Vercel dashboard → Settings → Domains → Add your domain
